PUT YOUR PHOTOS HERE
====================
1. Download free house photos (for example from unsplash.com or pexels.com) and check the licence.
2. Save them in this folder as JPG files, named after each home:

   miami-penthouse-1.jpg          (outside)   -2.jpg (living room)   -3.jpg (bedroom)
   austin-family-home-1.jpg
   la-cedar-villa-1.jpg
   seattle-harbor-condo-1.jpg
   denver-maple-cottage-1.jpg
   austin-lakeside-villa-1.jpg
   nyc-downtown-loft-1.jpg
   la-sunset-apartment-1.jpg
   nyc-parkslope-townhouse-1.jpg
   miami-seaside-studio-1.jpg
   (each one also needs -2.jpg and -3.jpg)

3. Open js/data.js and change   const USE_PHOTOS = false;   to   true

Tip: use 1600 x 1000 px images, about 200 KB each, so the site stays fast.
If a photo file is missing, the site shows the built-in illustration for that picture.
